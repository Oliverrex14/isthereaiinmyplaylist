How the 8-Point Forensics Pipeline Scores Each Track

VECTOR 01 // TIMELINE

Pre-AI Era Discography

Cross-checks Apple iTunes and Deezer release timestamps. Artists with verifiable catalog entries prior to 2023 pre-date modern commercial music generators (Suno/Udio).

VECTOR 02 // VELOCITY

Release Cadence & Single Ratio

Measures total releases in the trailing 12 months and calculates the Single-to-Album ratio. Synthetic stream farms typically upload 15–50+ single-track releases per year.

VECTOR 03 // REGISTRY

MusicBrainz & Copyright (℗/©)

Verifies whether the artist has a documented entity ID in the MusicBrainz database and inspects ℗/© phonographic copyright strings for anonymous DIY distributors.

VECTOR 04 // TELEMETRY

Audio Stream & Duration Window

Flags track durations clustering around 2:00 (120s) and 4:00 (240s) model context limits, and computes byte-level Shannon entropy (H), zero-crossing rate, and frame variance on preview streams.
